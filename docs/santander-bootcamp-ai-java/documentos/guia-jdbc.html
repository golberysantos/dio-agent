1. O que é e para que serve o JDBC?

O JDBC é uma API da plataforma Java Standard Edition (pacote java.sql) que padroniza o acesso a bancos de dados relacionais. Ela funciona como uma camada de abstração: o desenvolvedor escreve código Java padrão e a especificação JDBC se encarrega de traduzir essas chamadas para a linguagem nativa do banco de dados (SQL) utilizando um Driver específico fornecido pelo fabricante do banco de dados (PostgreSQL, MySQL, H2, etc.).

2. As 5 Interfaces Principais do JDBC

O funcionamento básico do JDBC baseia-se em cinco interfaces principais localizadas no pacote java.sql:

  • DriverManager: Classe responsável por carregar os drivers de banco de dados e estabelecer a conexão física com o banco através de uma URL de conexão JDBC.
  • Connection: Representa a conexão física ativa com o banco de dados. É a partir dela que criamos os comandos e controlamos as transações (commits e rollbacks).
  • Statement: Interface usada para executar comandos SQL estáticos de leitura ou gravação.
  • PreparedStatement: Subinterface de Statement usada para executar comandos SQL parametrizados (que contêm parâmetros representados por ?). Ela compila o comando SQL uma única vez e impede ataques de SQL Injection.
  • ResultSet: Representa a tabela de dados resultante de uma consulta SQL (SELECT). Ela mantém um cursor apontando para a linha atual de resultados.

3. Principais Métodos e Comandos do JDBC

No desenvolvimento diário com JDBC, os seguintes métodos são os mais utilizados:

  • DriverManager.getConnection(url, usuario, senha): Cria e retorna um objeto Connection.
  • conexao.prepareStatement(sql): Cria um objeto PreparedStatement a partir de uma string SQL.
  • stmt.setString(index, valor) / stmt.setDouble(index, valor): Define os valores dos parâmetros dinâmicos (placeholders ?) no SQL, sendo o índice baseado em 1 (1-indexed).
  • stmt.executeQuery(): Executa uma consulta SQL (SELECT) e retorna um objeto ResultSet.
  • stmt.executeUpdate(): Executa comandos de manipulação de dados (INSERT, UPDATE, DELETE) ou de definição de dados (CREATE TABLE), retornando o número de linhas afetadas.
  • rs.next(): Move o cursor do ResultSet para a próxima linha de dados. Retorna true se houver uma linha válida e false se atingir o fim dos resultados.
  • rs.getInt(coluna) / rs.getString(coluna): Recupera o valor de uma coluna da linha atual do ResultSet.

4. Exemplo de Fluxo Sequencial JDBC (Sem Analogias)

Abaixo está um exemplo de fluxo clássico sequencial do JDBC, mostrando a conexão, criação de tabela, inserção segura e consulta de dados:

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.Statement;
import java.sql.SQLException;

public class FluxoJDBCTradicional {
    public static void main(String[] args) {
        String url = "jdbc:h2:mem:fluxo_db;DB_CLOSE_DELAY=-1";
        String usuario = "sa";
        String senha = "";

        // Uso do try-with-resources para fechamento automático dos recursos
        try (Connection conn = DriverManager.getConnection(url, usuario, senha)) {
            
            // 1. Criar Tabela
            try (Statement stmt = conn.createStatement()) {
                stmt.execute("CREATE TABLE usuarios (id INT AUTO_INCREMENT PRIMARY KEY, nome VARCHAR(255))");
            }
            
            // 2. Inserir Registro Seguro
            String sqlInsert = "INSERT INTO usuarios (nome) VALUES (?)";
            try (PreparedStatement stmtInsert = conn.prepareStatement(sqlInsert)) {
                stmtInsert.setString(1, "Golbery Oliveira");
                stmtInsert.executeUpdate();
            }
            
            // 3. Consultar Registro
            String sqlSelect = "SELECT id, nome FROM usuarios";
            try (PreparedStatement stmtSelect = conn.prepareStatement(sqlSelect);
                 ResultSet rs = stmtSelect.executeQuery()) {
                
                while (rs.next()) {
                    int id = rs.getInt("id");
                    String nome = rs.getString("nome");
                    System.out.println("ID: " + id + " | Nome: " + nome);
                }
            }
            
        } catch (SQLException e) {
            System.out.println("Erro na execução do JDBC: " + e.getMessage());
        }
    }
}
