## 🚀 Como Executar os Projetos

Cada subpasta numerada representa um projeto independente. Para rodar:
1. Abra a pasta correspondente no seu editor (VS Code ou IntelliJ).
2. Certifique-se de ter o **JDK 21** instalado.
3. Importe como um projeto Maven/Gradle.
4. Execute a classe principal da aplicação.
